# Search RP UI

> Design System e Especificação Visual do Inventário Search RP

---

# Conceito

O inventário do Search RP segue uma identidade minimalista, premium e cinematográfica.

Referências:

- Escape from Tarkov
- Arena Breakout
- Ready or Not
- IV-HUD
- Afterlife UI

Princípios:

- Minimalismo
- Alto contraste
- Muito espaço negativo
- Poucos elementos coloridos
- Interface limpa
- Hierarquia forte
- Legibilidade acima de tudo
